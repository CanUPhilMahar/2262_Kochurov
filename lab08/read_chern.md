### Задание 3 **(2)**

Я написал такую программу используя один `break` с помощью того, что в Java можно писать имя для циклов.
Я использовал это, чтобы завершить внешний цикл, как только программа находит нуль.

Вот какие данные я использовал:
```
{1, 2, 3}
{4, 0, 6}
{7, 8, 9}
```

Код программы:
```java
public class Main {
    public static void main(String[] args) {
        int[][] a = {
            {1, 2, 3},
            {4, 0, 6},
            {7, 8, 9}
        };

        int fi = -1, fj = -1;

        outer:
        for (int i = 0; i < a.length; i++) {
            for (int j = 0; j < a[i].length; j++) {
                if (a[i][j] == 0) {
                    fi = i;
                    fj = j;
                    break outer; // Выход сразу из двух циклов
                }
            }
        }

        if (fi != -1) {
            System.out.println("Первый нуль: (" + fi + ", " + fj + ")");
        }
    }
}
```

### Задание 4 **(2)**

Цикл получился таким потому что список `a` изменяется прямо во время итерации. `a.pop()` удаляет последний элемент, а `x` берется по индексу с начала списка. То есть мы складываем первый элемент с последним, второй с предпоследним и так далее. Но так как длина списка уменьшается с каждым шагом, а индекс итерации растет, они встречаются ровно на середине.

Код:
```python
a = list(range(10))
b = [a.pop() - x for x in a]
print(*b)
```
Выведет `9 7 5 3 1`.
1. `x = 0`, `pop()` = 9, результат 9.
2. `x = 1`, `pop()` = 8, результат 7.
3. `x = 2`, `pop()` = 7, результат 5.
4. `x = 3`, `pop()` = 6, результат 3.
5. `x = 4`, `pop()` = 5, результат 1.
После этого индекс равен 5, а длина списка стала 5, поэтому цикл завершается.

### Задание 5 **(2)**

Программа на C++ с использованием только циклов по коллекции (range-based for):

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> v(n);
    for (int &x : v) {
        cin >> x;
    }

    int last = v.back();

    for (int &x : v) {
        x += last;
    }

    int positive = 0, negative = 0;

    for (int x : v) {
        if (x > 0) {
            ++positive;
        } else if (x < 0) {
            ++negative;
        }
    }

    cout << positive << " " << negative << endl;
    return 0;
}
```

### Задание 6 **(3)**

Фигурные скобки нужны для создания своей области видимости переменных.
Переменные с `__` это скрытые переменные, которые программист не увидит.

Главная задача этой новой функции - защита от изменения границ цикла. Благодаря тому, что `i` это константа, а `__n` это невидимая переменная, программист не может поменять границы цикла, что делает эту функцию истинной реализацией цикла со счётчиком.

Два основных различия:
1. **Счётчик `i` нельзя изменить внутри цикла** (он `const`).
2. **Граница `to` фиксируется при старте** и не меняется, даже если изменить переменную, переданную в `to`.

Демонстрация:
```cpp
#include <iostream>
#include <vector>

#define forc(i, from, to) { int __i = from, __n = to; for(const int &i = __i; i < __n; __i++) {
#define endfor } }

int main() {
    // 1. Защита счетчика
    forc(i, 0, 5) {
        std::cout << i << " ";
        // i++; // Ошибка компиляции, так как i - константа
    } endfor
    std::cout << "\n";

    // 2. Защита границ
    std::vector<int> v(5, 1);
    forc(i, 0, v.size()) {
        std::cout << i << " ";
        v.push_back(1); // Добавляем элементы, размер v.size() растет
    } endfor
    // Выведет 0 1 2 3 4, так как __n запомнил изначальный размер (5)
}
```

```python
a = [int(x) for x in input().split()]
for x in a:
    if x < 0:
        print(x)
        break
else:
    print("Отрицательных чисел нет")
```

Аналогичная программа на C++:
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> a;
    int x;
    while (cin >> x) a.push_back(x);

    bool found = false;
    for (int v : a) {
        if (v < 0) {
            cout << v << endl;
            found = true;
            break;
        }
    }

    if (!found) {
        cout << "Отрицательных чисел нет" << endl;
    }
    return 0;
}
```
Изменения в алгоритме: в C++ нет конструкции `for...else`, поэтому пришлось добавить логическую переменную `found`. Она нужна, чтобы после цикла понять, был ли выполнен `break`, или цикл дошел до конца.

### Задание 9 **(3)**

Программа на Python:
```python
def t(i):
    return i >= 2000

left = -1
right = 10**18

while right - left > 1:
    mid = (left + right) // 2
    if t(mid):
        right = mid
    else:
        left = mid

print(right)
```

**Инвариант цикла**: `t(left) == False` и `t(right) == True`.
Почему он выполняется:
До цикла мы задаем `left = -1` (заведомо ложь) и `right = 10**18` (заведомо истина).
Внутри цикла мы берем `mid`. Если `t(mid)` истина, значит `k` находится слева от `mid` или равен ему, поэтому мы сдвигаем правую границу (`right = mid`). Инвариант сохраняется, так как новое `right` истинно.
Если `t(mid)` ложь, значит `k` строго справа, сдвигаем левую границу (`left = mid`). Новое `left` ложно, инвариант снова сохранен.
Цикл заканчивается, когда `right - left == 1`. По инварианту `left` ложно, а `right` истинно. Так как между ними нет других чисел, `right` — это и есть первое истинное значение (искомое `k`).

### Задание 1 **(5)**

Чтобы найти сумму элементов матрицы только одним циклом, можно представить двумерный массив как одномерный, пробегая по нему индексами от `0` до `n*m - 1`.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> a(n, vector<int>(m));

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            cin >> a[i][j];
        }
    }

    long long sum = 0;
    // Один цикл для суммирования
    for (int idx = 0; idx < n * m; ++idx) {
        sum += a[idx / m][idx % m];
    }

    cout << sum << endl;
    return 0;
}
```

### Задание 2 **(15)**

Возьмем простую программу на C++ с циклом и ветвлением:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 10;
    int res = 0;

    // Ветвление (полная форма)
    if (a < b) {
        res = 1;
    } else {
        res = 2;
    }

    // Цикл
    for (int i = 0; i < 3; i++) {
        res += i;
    }

    return 0;
}
```

Если скомпилировать без оптимизации (например, `g++ -O0 -S`), мы получим ассемблерный код (x86). Опишем его основные части:

**1. Ветвление (if-else)**
В ассемблере нет блока `if`. Вместо этого используются команды сравнения и условного перехода.
```asm
    mov     eax, DWORD PTR [rbp-4]  ; загружаем a
    cmp     eax, DWORD PTR [rbp-8]  ; сравниваем a и b
    jge     .L2                     ; если a >= b, прыгаем на .L2 (блок else)
    mov     DWORD PTR [rbp-12], 1   ; res = 1
    jmp     .L3                     ; пропускаем else
.L2:
    mov     DWORD PTR [rbp-12], 2   ; res = 2 (блок else)
.L3:
```
В полной форме компилятор использует метку `jmp`, чтобы пропустить блок `else`. В краткой форме (без `else`) `jmp` бы не было, просто был бы условный переход.

**2. Цикл (for)**
Цикл `for` разворачивается в инициализацию, проверку условия и инкремент с помощью безусловного перехода.
```asm
    mov     DWORD PTR [rbp-16], 0   ; i = 0
    jmp     .L4                     ; прыгаем на проверку условия
.L5:
    mov     eax, DWORD PTR [rbp-16] ; загружаем i
    add     DWORD PTR [rbp-12], eax ; res += i
    add     DWORD PTR [rbp-16], 1   ; i++
.L4:
    cmp     DWORD PTR [rbp-16], 2   ; сравниваем i с 2
    jle     .L5                     ; если i <= 2, прыгаем в тело цикла (.L5)
```
Здесь видно, что цикл реализуется через проверку условия в конце/начале и команду условного перехода `jle` (jump if less or equal), которая возвращает выполнение в тело цикла.
